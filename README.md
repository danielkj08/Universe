# 🌌 Universe: 당신의 학업을 밝혀줄 은하계

**Universe**는 학생들의 효율적인 학습과 학교 생활을 돕기 위해 설계된 올인원 학업 보조 솔루션입니다. 급식 확인부터 정밀한 시간 측정까지, Universe 안에서 모든 학업 일정을 관리하세요.

### 🚀 주요 기능

### 🏫 학교 생활 매니저 (학교 탭)

* **실시간 급식 확인:** 우리 학교를 설정하고 오늘의 메뉴를 미리 확인하세요. 🍱
* **스마트 시간표:** 학년과 반을 설정하면 내 교실의 시간표가 자동으로 동기화됩니다. 🕒
* **선생님 실시간 반영:** 갑작스러운 수업 변경도 걱정 마세요! 선생님이 수정하신 정보가 **실시간으로 반영**되어 항상 정확한 정보를 제공합니다. 👨‍🏫


### 📅 스마트 캘린더

* 중요한 시험 일정, 수행평가 마감일을 한눈에 관리하세요.
* 학업과 개인 일정을 분리하여 체계적으로 기록할 수 있습니다. 🗓️


### ⏱️ 몰입 타이머 (타이머 탭)

* **뽀모도로 타이머:** 25분 집중, 5분 휴식! 과학적인 집중력 향상 기법을 활용해 보세요. 🍅
* **순공 시간 측정:** 내가 실제로 공부에 몰입한 시간을 정밀하게 측정하고 기록합니다. 🔥


### 📝 심플 메모

* 떠오르는 아이디어나 잊지 말아야 할 숙제를 가볍게 기록하세요. ✍️
* 군더더기 없는 깔끔한 인터페이스로 빠른 작성이 가능합니다.

### 📥 설치 방법 (Installation)

#### 🤖 Android (APK 설치 가이드)

최신 안드로이드 보안 정책에 따라 APK 파일을 직접 설치할 경우 아래의 과정을 확인해 주세요.

1. **파일 다운로드:** 제공된 `.apk` 파일을 기기로 다운로드합니다.
2. **보안 위험 자동 차단 해제 (삼성 갤럭시 등):**
    * 설정 > 보안 및 개인정보 보호 > **보안 위험 자동 차단** 메뉴로 이동합니다.
    * 활성화되어 있다면 잠시 **'사용 안 함'**으로 설정해야 설치가 가능합니다.
3. **출처를 알 수 없는 앱 설치 허용:**
    * 다운로드한 파일을 실행하면 나타나는 팝업에서 '설정'을 누릅니다.
    * '이 출처에서 설치 허용' 스위치를 켭니다.
4. **Google Play 프로텍트 경고:**
    * "차단됨" 팝업이 뜰 경우, '무시하고 설치' 또는 '세부 정보 보기'를 눌러 **'항상 설치'**를 선택하세요.

#### 💻 Windows

1. 제공된 압축 파일(`.zip`)을 원하는 경로에 압축 해제합니다.
2. 폴더 내의 **Universe** 실행 파일(exe)을 더블 클릭하여 앱을 시작하세요.
3. 별도의 설치 과정 없이 바로 사용 가능합니다.
